# Copyright headers

Every source file carries a header. It is what turns "this looks like ours" into a
documented claim, and it travels with a file when someone copies it out.

## Code files (.ts, .tsx, .js, .jsx, .css)

```
/*
 * Copyright © 2026 Stonemark Infrastructure Assurance LLC. All rights reserved.
 * Confidential and proprietary. No licence granted. See LICENSE.
 * SPDX-License-Identifier: LicenseRef-Stonemark-Proprietary
 */
```

## HTML

```
<!--
  Copyright © 2026 Stonemark Infrastructure Assurance LLC. All rights reserved.
  Confidential and proprietary. No licence granted. See LICENSE.
-->
```

## Markdown documents

Last line of the file:

```
© 2026 Stonemark Infrastructure Assurance LLC. Confidential and proprietary.
```

## The published demo page

The hosted page carries a visible footer line and an HTML comment:

```
<meta name="copyright" content="© 2026 Stonemark Infrastructure Assurance LLC">
```

Visible footer: `© 2026 Stonemark Infrastructure Assurance LLC · Sample data · Not an
assessment`.

## Rules

- Keep 2026 as the year of first publication. Add a second year only when material new
  content lands, as `© 2026–2027`.
- Do not add a header to a third-party file. Leave its own licence header intact; that
  header is the licence condition.
- Do not write a registration number, state of formation or address into a header until
  `PLACEHOLDERS.md` records it as confirmed.
